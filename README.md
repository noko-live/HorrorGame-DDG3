# HorrorGame-DDG3

What went well?

The process of the game was very straight forward so I didn't feel disappointed that I was missing anything.

What didn’t go well?

I had a moment where the player needed to turn behind them slowly so I the movement would work and so it would drastically switch. It kept bugging and it was bug I just couldn't figure out how to fix.

What challenges did you face? (Technical, creative, or production)
Ran into a few small issues outside of unity. I didn't know how to make the game naturally dark, so I fiddled around with the volume a lot to get the idea I wanted. 
Audio wise it has been a while since I use audacity, and I found out pretty quickly that for whatever reason it wasn't working anymore. So I decided to try REAPER which was a massive step and things were still familiar but
I got the basics down and probably very overkill.

What can you do differently next time?

Have more gameplay as a prototype? It felt like just a simple horror experience that's been redone so many times. I couldn't come up with something interesting enough to make in a short amount of time. Overall would have done a different idea.
